## Descripción
Agente inteligente que juega Cuadrito (Squares) con límite de tiempo usando búsqueda minimax.

## Archivos

| Archivo | Descripción |
|---------|-------------|
| **AzucarMorena.js** | Agente inteligente que implementa la lógica de juego usando búsqueda minimax con optimizaciones (transposition table, killer moves) |
| **squares.js** | Ambiente/motor del juego Cuadrito. Define las reglas y la estructura del tablero |
| **index.html** | Interfaz HTML que visualiza el juego y permite jugar contra el agente |

## Cómo usar

Abrir `index.html` en el navegador para jugar contra el agente AzúcarMorena.
